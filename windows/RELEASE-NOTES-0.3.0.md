# X-Bar Windows 0.3.0 beta

Release candidate documentation. Distribution is pending public signing and clean-PC installation/update validation.

## 한국어

- Windows 11 x64용 바탕화면 위젯과 Windows Widgets Board를 제공합니다. 설정에서 하나 또는 둘 다 선택할 수 있습니다.
- GitHub 배포판의 Windows Widgets Board 위젯은 개발자 모드가 필요합니다. 바탕화면 위젯 자체에는 필요하지 않습니다. 앱이 이 Windows 설정을 자동 변경하지 않습니다.
- 오늘 노출과 오늘·최근 2일·최근 7일 게시물의 노출·좋아요·재게시를 확인합니다. X Analytics 접근 권한이 있는 계정으로 앱 안에서 로그인합니다.
- 한국어·영어·일본어, 밝은/어두운 테마·고대비, 크기/위치 복원, 수집 중단·재시도·네트워크 복구를 지원합니다.
- 수동 확인과 하루 한 번 자동 업데이트 확인을 제공합니다. 사용자가 설치를 선택하면 서명·해시 검증 후 교체하고 다시 시작하며 로그인과 설정을 보존합니다.
- 베타 제한: ARM64와 장기 실행·물리 절전·다중 모니터 전체 조합은 검증되지 않았습니다. X 화면 구조 변경이나 계정 권한에 따라 수집이 제한될 수 있습니다.

## English

- Windows 11 x64 desktop widget and Windows Widgets Board, selectable individually or together.
- The GitHub edition's Windows Widgets Board widget requires Developer Mode. The desktop widget itself does not. The app does not change this Windows setting automatically.
- Today's impressions and post activity for today, the last two days or the last seven days. Sign in inside the app with an account that has access to X Analytics.
- Korean, English and Japanese; light/dark themes and high contrast; window placement; bounded collection, retries and network recovery.
- Manual checks and daily automatic update checks. Installation requires your choice, verifies the signed manifest/package, and restarts while preserving sign-in and preferences.
- Beta limits: ARM64, extended soak testing, physical sleep/resume and the full multi-monitor matrix remain unverified. X page changes and account permissions can affect collection.

## 日本語

- Windows 11 x64のデスクトップウィジェットとWindows Widgets Boardに対応。片方または両方を選べます。
- GitHub配布版のWindows Widgets Boardウィジェットには開発者モードが必要です。デスクトップウィジェット自体には不要です。このWindows設定をアプリが自動変更することはありません。
- 今日のインプレッションと、今日・過去2日・過去7日の投稿の反応を確認できます。Xアナリティクスを利用できるアカウントでアプリ内からログインしてください。
- 韓国語・英語・日本語、ライト/ダークテーマとハイコントラスト、ウィンドウ位置の復元、再試行とネットワーク復旧に対応します。
- 手動確認と1日1回の自動更新確認。インストールは利用者が選択し、署名とファイルを検証して更新・再起動します。ログインと設定を保持します。
- ベータの制限：ARM64、長時間稼働、実機のスリープ復帰、複数モニターの全組合せは未検証です。Xの画面構成やアカウント権限により収集が制限される場合があります。
