## 범위

한 대의 Windows 11 x64 PC에서 검증했다. 다른 PC, ARM64, 실제 재부팅·물리 절전 복귀·장기 실행은 추가 검증 대상이다. 새 비밀번호·2단계 인증 입력은 격리 시험 범위이며, 실계정 검증에는 저장된 로그인 세션을 사용한다. Windows 보안 정책을 변경하지 않는다. macOS 앱·Latest·appcast는 유지한다.

원본 시험 결과와 로컬 증거: `outputs/windows/release-0.4.2/`. 개인 계정 화면과 로그인 데이터는 공개 릴리스에 포함하지 않는다.
