# X-Bar 0.5.5 출시 검증

2026-10-30 · 0.5.5 (14) · macOS 14+ · Apple Silicon / Intel

X 분석의 새 `기간 선택` 버튼과 달력 구조에 대응한다. 버튼 문구, 달력 아이콘, 연결된 팝업을 함께 식별하고 시작일·종료일·선택한 셀의 연도를 검증한다. 닫힌 달력이나 이전 날짜의 정보를 재사용하지 않는다. 인식하지 못한 구조는 업데이트 안내로 구분한다.

게시물의 `icon-heart`·`icon-repost` 변형을 지원한다. Windows도 `app/Resources/ContentExtractor.js`를 사용해 운영체제별 구현 차이를 없앴다. 로그인 저장소·계정·설정 구조는 유지한다.

- 소스 commit: `845e9149a08b386785be466d14fc47a91d08376c`.
- 자동 검사: Swift 46, Safari 팝업 7, 화면 복구 22, WebKit 날짜·노출 61, 게시물 49 통과. 세션 취소·팝업 정리·변동 지표 통합 검사 통과.
- 실제 Apple Silicon Mac: 로그인된 X 계정에서 오늘 노출과 게시물 수집 확인. 오늘 → 최근 2일 → 오늘 변경과 앱 종료·재실행 후 수집 확인. 기존 5분 갱신과 로그인 유지.
- Developer ID 서명, universal 실행 파일, Apple 앱·DMG 공증 Accepted, stapling·Gatekeeper 검증 통과. 패키지에 포함된 JavaScript와 소스 commit 일치.
- 앱 공증 ID: `d59fb19a-f8a0-4ce8-851f-5ae67e754a3e`. DMG: `4cbe0bbc-412e-44f7-a280-0fb77655188a`.

주요 명령: `swift test`, `node --test`, `run-navigation-recovery.py`, `run-review-integration.py`, `swiftc -swift-version 6`, `build-local.sh`, `notarytool`, `stapler`, `package-release.py`, `prepare-update.py`.

Intel 실기기와 실제 OS 재부팅 후 동작은 미확인. 앱 재실행과 날짜·계정 전환·오래된 날짜 거부는 검증했다. 향후 X가 달력·통계 구조를 다시 바꾸면 추가 대응이 필요할 수 있다.
