# X-Bar 0.5.4 출시 검증

2026-10-27 · 0.5.4 (13) · macOS 14+ · Apple Silicon / Intel

- 새 버전을 처음 실행하면 Mac 로그인 항목에 등록합니다. 다음 로그인부터 메뉴바에서 시작합니다.
- 설정의 **Mac 로그인 시 자동 실행**으로 켜고 끌 수 있습니다. 앱이나 시스템 설정에서 끈 선택을 다음 실행에도 유지합니다.
- macOS 승인이 필요한 경우 로그인 항목 설정으로 안내하고, 등록 실패는 설정 화면에 표시합니다.
- 등록 전 macOS가 `notFound`를 반환하는 경우에도 최초 등록을 시도합니다. 별도 Developer ID 서명·샌드박스 앱에서 최초 등록, 해제, 해제 후 재실행 상태를 확인했습니다.
- 자동 검증 90개 통과: Swift 46, Safari 팝업 7, 분석 화면 복구 22, 자동 실행 상태 검사 15. 세션 취소·팝업 정리·변동 지표 통합 검사도 통과했습니다.

- 최종 앱 ZIP·DMG Apple 공증 `Accepted`, 공증 확인서 첨부·서명·Gatekeeper 검증 통과. ZIP과 DMG 안의 앱 파일·링크가 일치합니다.

주요 명령: `swift test`, `node --test`, `run-navigation-recovery.py`, `run-review-integration.py`, `swiftc` 자동 실행 검사, `build-local.sh`, `notarytool`, `stapler`, `codesign`, `spctl`, `prepare-update.py`.

앱 식별자·로그인 저장소·App Group과 기존 갱신 설정은 유지합니다. Intel은 빌드·서명을 검사했으며 실기기 실행은 미검증입니다. 실제 로그아웃·재부팅 후 자동 실행은 이번 검증에 포함하지 않았습니다.
