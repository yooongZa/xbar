# X-Bar 0.5.10 출시 검증

2026-11-15 · 0.5.10 (19) · macOS 14+ · Apple Silicon / Intel

Sparkle가 업데이트 파일 다운로드를 완료하면 업데이트 횟수를 기록한다. 설치별 임의 식별자·플랫폼·이전/대상 버전만 전송하며 같은 설치의 같은 대상 버전과 재전송은 중복 제외한다. 전송 실패는 업데이트를 막지 않으며 다음 실행에서 재시도한다. X 계정·게시물·쿠키는 전송하지 않는다.

- 소스: `2bae5f0ad9c1296aaa648b76fd655c4c0fbcf4de`.
- Swift 54개, Safari 팝업 7개, WebKit 수집 복구·통합 검사 통과.
- Developer ID universal 빌드, 앱·DMG 공증, stapling, 코드 서명·Gatekeeper 검사 통과.
- 앱 공증: `e981935a-8e10-498b-a7b1-f7bebc1d8dc5` · Accepted.
- DMG 공증: `5324d6ce-fe7c-47d0-9cde-c1c9ec782a0c` · Accepted.
- 공개 ZIP 재다운로드 SHA-256 일치. 기존 Sparkle 키로 ZIP·피드 검증, 이전 7개 피드 항목 유지.
- 실제 Apple Silicon Mac에서 공개 Sparkle 경로로 0.5.9 → 0.5.10 설치·재실행, 로그인·5분 갱신 설정·새 노출 수집 유지, 최신 버전 안내 확인.
- 설치된 실행 파일·Info.plist·코드 서명 리소스가 배포 파일과 일치.

수집은 0.5.10에서 이후 업데이트를 내려받을 때부터 시작한다. 이전 버전에서 이번 버전으로 업데이트한 횟수는 소급 수집하지 않는다. Intel 실기기 실행은 미확인.

주요 명령: `swift test`, `node --test`, `run-navigation-recovery.py`, `run-review-integration.py`, `xcodegen`, `build-local.sh`, `notarytool`, `stapler`, `package-release.py`, `prepare-update.py`, `codesign`, `spctl`, `gh release`.
