# X-Bar 0.5.9 출시 검증

2026-11-13 · 0.5.9 (18) · macOS 14+ · Apple Silicon / Intel

게시글의 노출 증가 속도가 10분 환산 1,000회 이상이면서 최근 평소 증가 속도의 5배 이상이면 무지개를 표시한다. 재게시 수는 판정에서 제외했다. `1.0M → 1.1M` 같은 축약 숫자는 연속 수집의 증가량을 최대 1시간 모아 비교한다. 기존 로그인·효과 설정·30분 반복 제한을 유지한다.

- 소스: `61fa4c5e83acb610d2da75e65816657965912a5e`.
- Swift 52개, Safari 팝업 7개 통과. WebKit 수집 복구·달력 및 세션·팝업·변동 지표 통합 검사 통과.
- Developer ID universal 빌드, 앱·DMG 공증, stapling, 코드 서명 및 Gatekeeper 검사 통과.
- 앱 공증: `e36e8af2-1658-40ea-8244-44220735b5f6` · Accepted.
- DMG 공증: `fdd0db1b-399d-44e9-a334-d3f2359dfc1d` · Accepted.
- Sparkle ZIP과 피드는 기존 키로 서명·검증했다. 이전 피드 항목을 보존했다.
- 실제 Apple Silicon Mac / macOS 27.2.1에서 변경 로직의 로컬 빌드와 로그인·게시글 20개 수집을 확인했다.

주요 명령: `swift test`, `node --test`, `run-navigation-recovery.py`, `run-review-integration.py`, `xcodegen`, `build-local.sh`, `notarytool`, `stapler`, `package-release.py`, `prepare-update.py`, `codesign`, `spctl`, `gh release`.

공개 ZIP·DMG·소스의 SHA-256, 공개 Sparkle 피드·ZIP 서명, 한국어·영어·일본어 다운로드·지원 페이지가 배포 파일과 일치함을 확인했다. 이전 6개 피드 항목을 유지했다.

실제 Mac의 공개 Sparkle 경로로 0.5.8(17) → 0.5.9(18) 설치·재실행을 확인했다. 설치된 실행 파일·Info.plist·코드 서명 리소스는 공개 ZIP과 일치하며, 로그인·오늘 수치 수집·5분 갱신 설정을 유지했다. 이번 감지 로직으로 실제 노출 급증 이벤트도 확인했다.
