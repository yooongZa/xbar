# X-Bar 0.5.3 출시 검증

2026-10-26 · 0.5.3 (12) · macOS 14+ · Apple Silicon / Intel

- 알림·홈 등으로 이동했을 때 분석 화면으로 자동 복귀합니다.
- 멈춘 읽기에 시간제한을 적용하고, 실패 시 30초부터 최대 5분 간격으로 재시도합니다.
- 로그인·인증번호·작성 중인 내용을 보호하고, 확인 중·재시도 대기·확인 필요 상태를 구분합니다.
- 자동 테스트 159개 통과: Swift 46, Safari 팝업 7, WebKit 노출 37·게시물 47, 자동 복구 22. 세션 취소·팝업 정리·변동 수치 통합 검증도 통과했습니다.
- 실제 계정에서 알림 페이지 이동 후 새로고침 없이 노출·인기 콘텐츠가 복구되는 것을 확인했습니다.
- 앱 ZIP·DMG Apple 공증 `Accepted`, 공증 확인서 첨부·서명·Gatekeeper 검증 통과. ZIP·DMG의 앱 파일·링크 93개 항목 일치.

주요 명령: `swift test`, `node --test`, `run-navigation-recovery.py`, `run-review-integration.py`, WebKit 검증, `build-local.sh`, `notarytool`, `stapler`, `codesign`, `spctl`, `prepare-update.py`.

Intel은 빌드·서명을 확인했으며 실기기 실행은 미검증입니다. X 웹사이트 구조 변경과 모든 인증 조합은 이 검증으로 보장하지 않습니다.
