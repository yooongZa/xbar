# X-Bar 0.5.2 (11) 출시 검증

2026-10-23 · macOS 14+ · Apple Silicon / Intel · 한국어 / English / 日本語

업데이트 기능, 앱과 Safari 확장의 버전 표시, 다국어 안내, 서명과 배포 파일을 점검했습니다. 아래 검증 범위에서 출시를 막는 기능 오류는 발견되지 않았습니다.

## 자동 검증

| 범위 | 결과 |
|---|---|
| Swift 핵심 로직 | 44개 성공 |
| Safari 팝업·연결 동의 | 7개 성공 |
| 실제 WebKit의 오늘 노출 추출 | 31개 성공 |
| 실제 WebKit의 게시물 추출 | 47개 성공 |
| 세션 취소·팝업 정리·변동 수치 통합 검증 | 성공 |
| Universal(유니버설) 빌드 | 앱·Safari 확장·Sparkle에 arm64와 x86_64 포함 |

총 **129개 자동 테스트**가 통과했습니다. 통합 검증에서 취소된 세션을 연결 상태로 만들지 않는지, 팝업이 해제되는지, 수치가 바뀌는 화면에서도 목록을 읽는지 확인했습니다.

주요 명령:

```sh
swift test --package-path app
node --test app/Tests/popup-tests.cjs
python3 app/Tests/run-review-integration.py
zsh app/build-local.sh OUTPUT_DIRECTORY
```

`WebKitHarness.swift`, `ContentWebKitHarness.swift`는 `swiftc -swift-version 6 -framework AppKit -framework WebKit`로 각각 컴파일해 `Extractor.js`, `ContentExtractor.js`에 실행했습니다.

## 앱·업데이트 동작

- 공증된 최종 앱에서 기존 X 로그인, 오늘 노출, 최근 2일·7일 게시물 목록을 확인했습니다. 오늘 게시물이 나타나지 않는 경우의 안내도 확인했습니다.
- 설정의 0.5.2 버전 표시·업데이트 확인 버튼·자동 확인 스위치를 확인했습니다.
- 별도 샌드박스 앱에서 설치 선택 한 번으로 두 번의 실제 앱 교체·재실행을 검증했습니다. 기존 설정, 자동 확인 꺼짐, 합성 WebKit 쿠키가 유지됐습니다.
- 설치 전 취소, 다운로드 중 취소, 서명 후 변조한 feed(업데이트 목록)와 ZIP 차단을 확인했습니다.
- 설치 선택은 화면별로 관리하고 취소·오류·다음 화면·재실행에서 초기화합니다. 자동 설치는 비활성화 상태입니다.

## 공증과 패키징

- Developer ID Application 서명, Hardened Runtime(강화된 실행 환경), 샌드박스 설정을 확인했습니다.
- 앱 ZIP과 설치용 DMG 모두 Apple 공증 **Accepted**, 공증 로그의 issues(문제) 없음.
- 앱·DMG에 staple(공증 확인서 첨부) 후 `stapler validate`, `codesign --verify --deep --strict`, Gatekeeper 검사를 수행했습니다.
- 배포용 ZIP의 앱과 읽기 전용으로 연 DMG의 앱이 파일·링크 단위로 일치하는지 확인했습니다.
- 패키징 과정에서 Finder 메타데이터가 서명 검사를 방해할 수 있어 별도 임시 폴더에서 이를 정리하고 재검증하도록 도구에 반영했습니다.
- 최종 ZIP으로 Sparkle 서명과 appcast를 생성합니다. 저장소의 공개키에 대응하는 개인키는 Keychain(키체인)에 유지합니다.

Apple의 [공증 절차](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)와 [공증 확인서 첨부 절차](https://developer.apple.com/documentation/security/customizing-the-notarization-workflow)를 따랐습니다. Apple 공증은 App Store 심사와 별도입니다.

## 검증 범위

실행 확인은 macOS 27.0.1의 Apple Silicon에서 수행했습니다. Intel 바이너리는 빌드·서명·포함 여부를 확인했으며 Intel 실기기 실행은 수행하지 않았습니다. 새 계정의 첫 로그인·모든 2단계 인증 조합, 장시간 잠자기·오프라인, 전원 차단 중 복구는 이번 출시 검증 범위 밖입니다. X 페이지 구조나 응답이 변경되면 앱 업데이트가 필요할 수 있습니다.

통합 시험의 기존 `ControllerHarness.swift`에는 실행에 영향을 주지 않는 weak 변수 컴파일 경고 1건이 남아 있습니다.
