# X-Bar

오늘의 X 노출과 글의 반응을 Mac 메뉴바에서 확인하는 앱입니다. 현재 TestFlight 내부 테스트 중입니다.

- [사용 안내 및 지원](https://yooongza.github.io/xbar/support.html)
- [개인정보처리방침](https://yooongza.github.io/xbar/privacy.html)

macOS 14 이상, X 로그인 및 분석 화면 접근 권한이 필요합니다. Safari 연결과 앱 내 로그인을 지원합니다.

이 저장소는 공개 안내 문서만 포함합니다. 앱 소스와 사용자 로그인 정보는 포함하지 않습니다.
