X-Bar 개인정보처리방침

기준 버전 0.5.0 · 작성일 2026년 10월 22일

앱에서 처리하는 정보

X-Bar는 사용자가 로그인한 X 분석 화면에서 계정명, 오늘 노출 수, 게시물 미리보기, 노출·좋아요·재게시 수를 읽어 표시합니다. 이 정보와 증가량 비교 기록은 앱 메모리에서 처리하며 앱을 종료하면 사라집니다. 갱신 주기와 표시 설정은 Mac에 저장합니다.

웹 로그인과 외부 서비스

X 웹사이트는 앱 안의 WebKit 화면에서 열립니다. 로그인 쿠키와 웹 저장소는 이 Mac의 앱 전용 저장소에 보관됩니다. X-Bar 개발자는 비밀번호를 별도로 읽거나 저장하는 기능을 구현하지 않았으며, 계정과 지표를 개발자 서버로 전송하지 않습니다.

X 웹사이트는 로그인, 분석 화면 제공 및 자체 서비스 운영을 위해 정보를 처리할 수 있습니다. X와의 웹 통신에는 X 개인정보처리방침이 적용됩니다. 개발자 서버가 없다는 설명은 X 웹사이트의 데이터 처리가 없다는 뜻이 아닙니다.

Safari 연결

사용자가 Safari 연결을 선택하고 확장에서 동의한 경우, x.com의 로그인 쿠키 auth_token·ct0·twid를 이 Mac의 X-Bar로 전달합니다. App Groups의 임시 전달 파일은 암호화하며, 복호화 키는 실행 중인 앱 메모리에만 둡니다. 확장 설정과 X 로그인 준비에는 시간 제한을 두지 않습니다. 사용자가 연결 버튼을 누르면 60초 동안 유효한 일회성 전달 요청을 만듭니다. 만료되면 로그인 상태를 유지한 채 다시 연결할 수 있습니다. 앱이 전달 정보를 읽으면 임시 파일을 삭제하고, 로그인 쿠키는 앱 전용 WebKit 저장소에 보관합니다. 다른 사이트의 쿠키와 저장된 비밀번호는 읽지 않습니다.

연결 해제와 삭제

X-Bar 설정에서 ‘연결 해제’를 선택하면 앱의 WebKit 웹 데이터와 현재 표시·비교 정보를 삭제합니다. Safari의 로그인 상태에는 영향을 주지 않습니다. 앱을 종료하면 갱신이 멈춥니다.
