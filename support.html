X-Bar 지원

X 분석 화면의 오늘 노출 수와 콘텐츠 반응을 Mac 메뉴바에서 확인하는 앱입니다.

시작하기

  1. X-Bar를 실행하고 X 연결 화면을 엽니다.
  2. 시작 안내에서 Safari 연결 또는 앱에서 직접 로그인을 선택합니다. X 분석 화면 접근 권한이 필요합니다.
  3. 오늘 노출 수가 표시되면 창을 숨깁니다. 메뉴바 숫자를 눌러 콘텐츠를 확인하세요.

자주 묻는 질문

창을 닫아도 갱신되나요?

X-Bar가 실행 중이면 갱신을 시도합니다. 앱 종료·Mac 잠자기·로그인 만료 중에는 갱신이 멈추거나 늦어질 수 있습니다.

오늘 / 최근 2일 / 최근 7일은 무엇인가요?

글을 게시한 날짜 범위입니다. 최근 2일은 어제부터 오늘까지, 최근 7일은 오늘을 포함한 최근 7일입니다. 글별 수치는 X에 표시된 전체 횟수입니다. 상단 계정 총노출은 오늘 값입니다.

관찰 후 증가는 무엇인가요?

앱이 글을 처음 확인한 뒤 늘어난 노출 수입니다. 1,000에서 1,200이 되면 +200입니다. 앱 재시작·날짜·시간대·계정·기간 변경 시 기준이 초기화됩니다.

Safari 로그인도 쓸 수 있나요?

Safari 확장을 X-Bar 앱에 포함했습니다. Safari 설정에서 확장을 켜고 x.com 접근을 허용한 뒤, 확장에서 ‘𝕏-Bar에 연결’을 누릅니다. 로그인 세션은 이 Mac의 X-Bar로 전달됩니다. 앱 안에서 X 아이디로 직접 로그인하는 방법도 있습니다. Chrome 연결은 제공하지 않습니다.

값이 갱신되지 않아요.

마지막 확인 시각을 확인하고 새로고침을 누릅니다. 계속 실패하면 X 연결 화면에서 로그인 상태와 분석 접근 권한을 확인하세요. X 화면 구조가 바뀌면 앱 업데이트가 필요할 수 있습니다.

RT 급증은 X 공식 기준인가요?

X-Bar가 재게시 증가 속도를 비교하는 자체 기준입니다. 효과는 설정에서 끌 수 있습니다.
